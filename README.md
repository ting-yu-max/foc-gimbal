# 单轴 FOC 云台稳定器

> 基于 STM32 + 手写 FOC 核心算法（Clarke / Park / SVPWM / 串级 PID）的单轴无刷云台稳定器。
> **不依赖 SimpleFOC 等现成库**，坐标变换、SVPWM、PID、互补滤波全部从零手写，配合 AS5600 磁编码器实现有感闭环，MPU6050 解算姿态。

---

## ✨ 项目亮点

- **FOC 核心算法全手写**：反 Park 变换、SVPWM（零序注入法）、速度 PI、位置 P、姿态环，逐行可讲清原理，不黑盒。
- **完整串级控制链路**：开环转动 → 速度闭环 → 位置闭环 → 姿态闭环（pitch 反馈），层层递进已逐级验证。
- **有感自同步闭环**：AS5600 编码器对齐 + 电角度自同步，解决了「闭环不转/手拨一顿一顿」的经典 d/q 轴错位坑。
- **电压模式驱动**：贴合云台电机 + 无电流采样驱动板的硬件现实，不强行上电流环（避免超纲）。
- **IMU 姿态解算**：MPU6050 加速度计 + 陀螺仪**互补滤波**融合 pitch，并用「为什么不用卡尔曼」的选型论证体现工程权衡。
- **从硬件到算法独立完成**：自接线、CubeMX 配外设、CMake 构建、OpenOCD 一键烧录，全链路打通。

> 📌 **实测进度**：开环转动 / 闭环自转 / 速度环 / 位置环（保位 + 手拨回弹）/ MPU6050 互补滤波 pitch 均**已实测通过**；姿态环为**代码级实现**（控制逻辑已闭环，因未做机械云台联调，暂未整机体感测试）。

## 🏗️ 系统架构

```
                         ┌──────────────── MPU6050 (pitch) ──────────────┐
                         │  互补滤波：0.96·陀螺积分 + 0.04·加速度计        │
                         ▼                                                │
   目标姿态 ──▶ 姿态环(P) ──▶ 速度目标 ──▶ 速度环(PI) ──▶ Uq ──▶ ┌────────┴────────┐
                                                              │   FOC 核心算法   │
   AS5600 ──▶ mech_angle ──▶ 位置环(P) ──┐                    │  反Park→SVPWM   │
                          (机械角反馈)    │                    │   → 三相 PWM    │
                                          └──速度反馈──        └────────┬────────┘
                                                                       ▼
                                                              ┌─────────────────┐
                                                              │  2804 无刷电机   │
                                                              └─────────────────┘
```

**串级思想**：外环慢、内环快；外环输出 = 内环目标。位置环 / 姿态环（外，P）输出速度目标 → 速度环（内，PI）输出电压 Uq → FOC 把 Uq 变换成三相 PWM。

## 🧠 核心算法

### 1. 坐标变换（反 Park）

把 dq 旋转坐标系下的电压（Vd 励磁 / Vq 转矩）变换到静止 αβ 系：

```
Vα = Vd·cosθ − Vq·sinθ
Vβ = Vd·sinθ + Vq·cosθ
```

令 `Vd = 0`，只留 `Vq` 控制力矩 → 代码见 [foc.c: inv_park()](Core/Src/foc.c)。

### 2. SVPWM（零序注入法）

αβ → 三相占空比。相比简单中心对齐，**动态零序注入** `Vn = −(max+min)/2` 可让三相对称、母线电压利用率 +15%，是七段式 SVPWM 的等效写法：

```
Va = Vα,  Vb = −0.5·Vα + 0.866·Vβ,  Vc = −0.5·Vα − 0.866·Vβ
duty = (Vx + Vn) / VDC + 0.5      （归一化到 0~1 占空比）
```

### 3. 串级 PID

| 环 | 反馈 | 输出 | 说明 |
|----|------|------|------|
| 姿态环（外） | pitch | vel_target | `err = −pitch`（角度→速度指令）|
| 位置环（外） | mech_angle | vel_target | 带跨界最短角差处理 |
| 速度环（内） | vel_filt（差分+低通）| uq_out | PI，双限幅防饱和/失步 |

### 4. 闭环电角度自同步

```
elec = mech_angle × POLE_PAIRS − zero_electric_angle + π/2
```

🔑 关键坑：对齐把 d 轴吸到 90° 方向，闭环**必须补 `+π/2`** 把磁场挪到 q 轴（超前转子 90°）才产生驱动力矩；不补则磁场压在 d 轴，电机不转、手拨一顿一顿。

### 5. IMU 互补滤波（MPU6050）

```
pitch = 0.96·(pitch + gyro_y·dt) + 0.04·pitch_acc
pitch_acc = atan2(−ax, az)·180/π      （加速度计，长期校正漂移）
gyro_y    = gy / 131                    （陀螺仪，短期抗振）
```

陀螺仪当主力（动态准），加速度计少量校正（静态准），一参数、计算量小、原理可讲透。

## 🚀 快速开始

### 环境要求

- **arm-none-eabi-gcc**（ARM 交叉编译工具链）
- **CMake ≥ 3.22** + **Ninja**（或 Make）
- **OpenOCD**（烧录）+ **ST-Link V2**
- VS Code（推荐，配 STM32CubeIDE 扩展用于 CubeMX 配置）

### 构建

```bash
# 在工程根目录
cmake -B build/Debug -G Ninja
cmake --build build/Debug
```

### 一键烧录（OpenOCD）

```bash
cmake --build build/Debug --target flash
```

一条命令完成「编译 + 烧录 + 校验 + 复位 + 退出」，用完即退不占端口。CMakeLists.txt 里已配好 `flash` 目标。

### 运行

1. 按 [硬件接线.md](硬件接线.md) 接好信号线，**先不给电机 VM 上电**，确认 F407 跑起、I2C 能读 AS5600 / MPU6050。
2. 串口（921600, 8N1）连 VOFA+，可看到 `zero_electric_angle` / `pitch` 等输出。
3. **再给驱动板 VM 上 12V**，电机对齐 → 闭环自转 → 进入位置环保位。

## 🐛 调试踩坑记录（）

完整记录见 [项目进度.md](项目进度.md)，摘录关键几例：

- **闭环不转、手拨一顿一顿** → 磁场落 d 轴（位置锁定）非 q 轴。根因是对齐零点定在 d 轴，闭环电角度需补 `+π/2`。改一行恢复驱动。
- **位置环加上后电机一直转停不住** → 不是方向反（位置环是负反馈），而是 `ANGLE_KP`/`VEL_LIMIT` 太大 → 高速冲目标过冲振荡。降到 0.5 / 3.0 平滑逼近即可停住。
- **Uq 大时测速异常、电机「飞快」断电即停** → I2C 被电机大电流噪声干扰，读数失败 → `mech_angle` 不准 → FOC 失步抖动（无惯性）。降 Uq 限幅绕开，根治靠加强上拉 + 线远离电机线。
- **MPU6050「无输出」** → 实为烧的是旧固件（打印 vel），新代码从未烧进去。换 OpenOCD 命令行烧录解决。

## ⚖️ 关键技术决策

- **电压模式 FOC（非电流模式）**：驱动板无相电流采样，云台电机低 KV，电压模式天然适配，不强行上电流环。
- **AS5600 有感控制（非无感）**：本科生体量，无感观测器（SMO/高频注入）超纲，有感更直接可靠。
- **互补滤波（非卡尔曼）**：单轴低速云台精度瓶颈在电压驱动 + I2C 噪声，不在算法；互补滤波一参数、计算量小、原理可讲透，卡尔曼是过度设计。
- **手写核心算法（非 SimpleFOC）**：嵌入式岗位标准技能，本科生可达，逐行可控、可讲。

## 📌 已知局限与后续

- 姿态环为**代码级实现**，未做机械云台联调（缺机械结构），整机体感待后续补机械件后验证。
- I2C 抗电机噪声能力有限，强电流区需硬件加固（上拉电阻 / 走线 / 滤波电容）。
- 无相电流采样，力矩控制精度受限于电压模式。
